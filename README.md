# Peta indikasi luapan Kali Celeng Q25

Peta interaktif 44 penampang model HEC-RAS Celeng, dengan status indikasi luapan, tautan Google Maps, dan unduhan CSV, KML, serta GeoJSON.

## Buka peta

https://flaxee1125.github.io/peta-luapan-celeng/

## Cakupan dan keterbatasan

- Peta ini menampilkan skenario Q25; hasil Q95 terpisah tidak ditampilkan pada peta ini.
- 14 penampang terindikasi luapan, 1 marginal (RS2200), 29 tidak terindikasi luapan.
- Indikasi membandingkan muka air hasil p05 dengan tebing pada geometri/gambar terakhir; terdapat perubahan geometri setelah komputasi.
- Koordinat menggunakan asumsi WGS84 / UTM zona 49S; datum sumber belum diverifikasi.
- Pin menunjukkan lokasi penampang dan titik tebing, bukan batas luas genangan maupun verifikasi banjir lapangan.
- Peta dasar OpenStreetMap dan Leaflet dimuat melalui internet.
